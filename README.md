# Feedback Collection System 📝

A simple **Python-based Feedback Collection System** that allows users to submit feedback with a rating and view all submitted feedback.

## 📌 Features

* Give feedback by entering your name
* Enter a feedback message
* Give a rating from **1 to 5**
* View all submitted feedback
* Displays the feedbacker's name, feedback, and rating
* Simple menu-driven system
* Exit the program anytime

## 🛠️ Technologies Used

* **Python**
* Lists
* Dictionaries
* `while` loop
* `if-elif-else`
* `input()` and `print()`

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or Command Prompt.
4. Run the Python file:

```bash
python feedback.py
```

## 💻 How It Works

The program displays three options:

```text
1. Give Feedback
2. View Feedback
3. Exit
```

### 1. Give Feedback

The user enters:

* Name
* Feedback
* Rating from 1 to 5

The information is stored in a list of dictionaries.

### 2. View Feedback

Displays all feedback submitted during the current program session.

### 3. Exit

Closes the program and displays a thank-you message.
