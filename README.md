# Feedback Collection System

A simple Python beginner project that allows users to submit, view, and delete feedback with a rating from 1 to 5.

## Features

* Add customer feedback
* Give rating from 1 to 5 ⭐
* View all feedback
* Delete feedback
* Validates the rating
* Simple menu-based system

## Technologies Used

* Python

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run the Python file:

```bash
python Feedback.py
```

## Example

```text
===== FEEDBACK COLLECTION SYSTEM =====
1. Give Feedback
2. View Feedback
3. Delete Feedback
4. Exit

Enter your choice: 1
Enter your name: Riddhi
Enter your feedback: Very good service
Give rating (1-5): 5

Feedback submitted successfully!
```
